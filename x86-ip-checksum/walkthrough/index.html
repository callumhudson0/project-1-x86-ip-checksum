Six ideas to know first

Assembly is just these ideas, repeated. If a line below confuses you, the answer is almost always one of these.

Registers are tiny boxes in the CPU

The CPU has a few named boxes that each hold one number: RAX, RBX, RCX, RDX, RSI and RDI. Almost every instruction works on them. AL is just the lowest 8 bits (one byte) of RAX.

mov rax, 5 ; RAX is now 5

One line does one tiny thing

The first word is the instruction. The destination comes first, then the source.

add rax, rbx ; RAX = RAX + RBX inc rsi ; RSI = RSI + 1

Labels name places in memory

A label like total: is a name for an address. Without brackets you get the address. With brackets you get the value stored there.

mov rcx, prompt ; the address mov rax, [total] ; what's stored there

Characters are numbers

Text is stored as ASCII codes. '0' is 48, '9' is 57, '.' is 46, a space is 32 and the Enter key's newline is 10 (0xA).

'7' - '0' = 55 - 48 = 7

An “if” is a compare plus a jump

cmp compares two values and sets the flags. The jump on the next line reads the flags and either jumps to a label or falls through to the next line.

cmp al, '.' je gotDot ; jump if equal

Ask Linux with int 0x80

Your program can't read the keyboard or print by itself. It puts a request number in RAX (3 read, 4 write, 1 exit), the details in RBX, RCX and RDX, then runs int 0x80. call and ret work like a function call and return.

mov rax, 4 ; write int 0x80
